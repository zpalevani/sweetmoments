# Sweet Moment Cake

Fresh, handmade cakes that turn birthdays, celebrations, and thoughtful gifts into sweet moments through personalized designs and convenient local delivery.

**Live site:** https://zpalevani.github.io/sweetmoments/

## About

Sweet Moment Cake is a handmade cake delivery brand, currently in the planning stage. This repo holds the public landing page and the early business planning docs for the project.

## Repo structure

- `docs/` — the landing page (served live via GitHub Pages from this folder)
  - `index.html`, `styles.css`, `script.js` — page structure, styling, and mobile nav / form validation
  - `assets/` — hero and product imagery
  - `README.md` — notes specific to the landing page
- `2026/Sweet Moment Cake/` — business planning notes (business model canvas, launch priorities)

## Local preview

To view the landing page without the live link, open `docs/index.html` directly in a browser — no build step required.

## Status

The site is a working front end; the consultation form currently validates in-browser and shows a confirmation message but isn't yet wired up to an email service or backend. The business plan is still in the planning stage — see `2026/Sweet Moment Cake/Sweet Moments.md` for goals and launch priorities.
