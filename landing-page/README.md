# Sweet Moment Cake Landing Page

A responsive, self-contained landing page based on the Sweet Moment Cake website brief.

## Open

Open `index.html` in a browser. No installation or build step is required.

## Files

- `index.html` - page structure and content
- `styles.css` - responsive visual design
- `script.js` - mobile navigation and consultation-form validation
- `assets/hero-cake.png` - generated hero photograph
- `assets/signature-collection.png` - generated product collection photograph

## Form

The consultation form currently validates in the browser and shows a confirmation message. Connect it to an email service, form platform, or website backend before publishing.

## Generated Image Prompts

The images were created with the built-in image generation tool.

### Hero

Warm editorial food photograph of a handmade berry celebration cake with ivory buttercream, blush floral piping, fresh berries, and the custom message "you are so loved"; sunlit cream setting; cake on the right with negative space on the left.

### Signature Collection

Warm editorial collection photograph featuring a mini cake and cupcake gift box, a berry bloom celebration cake, and a premium summer garden event cake in a cream, blush, raspberry, and sage palette.
